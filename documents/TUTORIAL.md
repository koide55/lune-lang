# Lune チュートリアル — 教科書に統合されました

このチュートリアル（全20章）は、教科書『プログラミング言語 Lune』に統合されました。

**→ [教科書『プログラミング言語 Lune』](https://koide55.github.io/lune-lang/book/)**
（[1冊にまとめた PDF](https://koide55.github.io/lune-lang/book/lune-book.pdf)、原稿は [books/](../books/README.md)）

**短い1周が欲しいときは、教科書の第1章だけを読んでください。** 1時間ほどで、書いて・動かして・壊すところまで行けます。チュートリアルが果たしていた役割はこれです。

## どこへ行ったか

| チュートリアルで読んでいたもの | 教科書の該当箇所 |
| --- | --- |

| 第2〜6章 遅延評価・サンク・メモ化 | **第4章 遅延評価 — Lune の心臓部**（`:thunks` / `:trace` で評価の瞬間を観察します） |
| 第7章 `fn` と部分適用 | 第3章 関数 |
| 第8〜9章 ADT とパターンマッチ | 第5章 代数的データ型とパターンマッチ |
| 第10章 レコード | 第6章 レコード |
| 第11章 null | 第7章 null 安全 |
| 第12章 標準ライブラリ | 付録B 標準ライブラリリファレンス（prelude 全41個） |
| 第13〜14章 `while` / `for` | 第9章 命令的に書く |
| 第15章 モジュール | 第10章 モジュール |
| 第16章 型チェックとツール | 第12章 REPL・整形・検査 |

無限リストとストリーム（第8章）、複数ファイル構成の実例、設計の理由（付録E）は、教科書で新しく足された部分です。

## なぜ畳んだのか

同じ内容を2箇所で維持していたからです。畳む前に照合したところ、**チュートリアルにあって教科書に無い言語機能・診断コード・REPL コマンド・標準ライブラリ関数はゼロ**でした（教科書は診断34種に触れ、prelude の41個すべてを載せています）。残っていた差は「英語で読める」ことと「短い」ことだけで、前者は[英語版](https://koide55.github.io/lune-lang/book/en/)ができたことで、後者は「第1章だけ読む」で解決します。

このファイルは、参照している URL が残っているため（PyPI に公開済みの説明文など）、案内として置いてあります。内容は git の履歴に残っています。
